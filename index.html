Bunnyland

Persistent ECS social sandbox

A shared world for players, admins, scripts, and AI agents.

An open-source simulation server. Humans and LLM-driven characters share one living world and play it with the same commands.

Start playing Guides Join the Discord

Three ways to play:

  • Toon Client — a room-by-room view in your browser.
  • Discord — Discord commands in a server channel.
  • Terminal — the Textual TUI or the line REPL (below).

Terminal play

Play from a shell.

Install with uv sync --extra tui / --extra repl (or run the published containers), then connect:

Textual TUI

bunnyland-tui --server …

Line REPL

bunnyland-repl --server …
